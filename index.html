Vibe-IC is an AI-native IC design plugin for Claude Code that drives a deterministic flow from natural-language intent through L1-L13 design documents, RTL, FPGA verification, and tape-out sign-off — with every step gated by real checkers, not LLM judgement.

What it does

01

Plan

Natural-language intent or existing datasheet → 13 layered design documents (L1 Description through L13 Test Sequence) as machine-readable JSON.

02

Build

L9 Integration Spec → single-agent RTL generation → Verilator lint → Icarus simulation → SymbiYosys formal → cocotb coverage.

03

Verify

Quartus / Vivado synth → bitstream burn → on-board protocol verification with Keysight-class scope + USB-HID tester support.

04

Sign off

OpenSTA multi-corner → DFT scan chain + ATPG → OpenROAD PnR → KLayout DRC → Netgen LVS → GDSII tape-out package.

Every transition is gated by a canonical-flow compliance check — no phase can be skipped, no sign-off can be silently waived. A chip-AGNOSTIC source guard keeps private IC names from leaking into the open codebase.

Quick start

1. Pull the open-source EDA toolchain (Docker)
docker pull hpretl/iic-osic-tools:latest
2. Install the MCP server
git clone https://github.com/vibeic/vibe-ic.git
cd vibe-ic/mcp-eda-server
npm install
claude mcp add eda-tools node "$PWD/src/index.js"
3. Install the Claude Code plugin
claude plugin marketplace add ../vibe-ic-marketplace
claude plugin install vibe-ic
4. Design something
claude "Design a temperature sensor IC: I2C, 12-bit,
        alert output, SOIC-8 package."

Optional: a Cyclone- or MAX10-class FPGA (we test on Terasic DE10-Lite), a USB scope (we test on Keysight DSO-X 3014T), and Intel Quartus Prime Lite (free).

Why it exists

Determinism over heuristics

Every check is a Python program with a fixed verdict tier (PASS / PASS_WITH_WAIVERS / FAIL). No LLM-judged "looks fine".

Chip-AGNOSTIC by construction

An externalised deny-list + a CI-wired guard test enforce that no private IC, vendor, or protocol name can leak into the public source tree.

Real-benchmark fixtures

Every walker / regex / merge patch ships with a real-world doc-shape fixture, not just a synthetic minimal case. Synthetic tests pass; real ICs fail. We pay that cost upfront.

Open all the way down

Wraps OpenROAD, Yosys, KLayout, Magic, ngspice, cocotb, and friends. Apache-2.0 licensed with explicit patent grant. Bundling-compatible with SkyWater, GF180MCU, IHP PDKs.
